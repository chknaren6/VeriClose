# ADR-001: Deterministic Verification Before AI Investigation

## Status

Accepted.

## Context

Finance arithmetic and matching must be reproducible, while narrations and exception communication may be unstructured.

## Decision

Deterministic rules own normalization, calculations, proof levels, metrics and journal validation. AI receives structured evidence only after rule execution and returns advisory structured output.

## Alternatives

- LLM-first matching was rejected because it is difficult to reproduce and measure safely.
- No AI was rejected because grounded explanation and communication drafting still add value.

## Consequences

The application works without a model key. AI quality cannot silently change auto-clear decisions.
